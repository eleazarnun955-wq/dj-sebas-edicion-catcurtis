# DJ SEBAS EDICIÓN CATCURTIS

Android video editor project inspired by modern mobile editors.

## Build

Open with Android Studio or run `./gradlew assembleDebug`.

The GitHub Actions workflow builds a debug APK and publishes it as an artifact.

## Current foundation

- Android app with a dark editing-studio interface
- Import videos, photos and audio from device storage using Android's system picker
- Media bin and editable clip timeline
- Preview player for imported video
- Export pipeline foundation; advanced multi-layer rendering, transitions and effects are staged for subsequent iterations

This is an independent application package: `com.djsebas.catcurtis`.
